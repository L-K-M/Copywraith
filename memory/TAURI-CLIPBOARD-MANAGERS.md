# Tauri Clipboard Managers

A list of clipboard managers and clipboard-related apps from the [awesome-tauri](https://github.com/tauri-apps/awesome-tauri) collection.

## Clipboard Managers

| Name | Description | Repository |
|------|-------------|------------|
| **Clippy** | Clipboard manager with sync & encryption | [github.com/0-don/clippy](https://github.com/0-don/clippy) |
| **EcoPaste** | Powerful open-source clipboard manager for macOS, Windows and Linux(x11) platforms | [github.com/ayangweb/EcoPaste](https://github.com/ayangweb/EcoPaste) |
| **PasteBar** | Limitless, Free Clipboard Manager for Mac and Windows. Effortless management of everything you copy and paste | [github.com/PasteBar/PasteBarApp](https://github.com/PasteBar/PasteBarApp) |
| **Qopy** | The fixed Clipboard Manager for Windows and Mac | [github.com/0PandaDEV/Qopy](https://github.com/0PandaDEV/Qopy) |
| **Lanaya** | Easy to use, cross-platform clipboard management | [github.com/ChurchTao/Lanaya](https://github.com/ChurchTao/Lanaya) |
| **Stacks** | Modern and capable clipboard manager for macOS. Seeking Linux and Windows contributions | [github.com/cablehead/stacks](https://github.com/cablehead/stacks) |
